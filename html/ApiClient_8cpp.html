Detailed Description

HTTP+JSON client for marketplace API implementation.

Implements the client-side API surface used by the ncurses UI. All network communication uses cpp-httplib and JSON.

Sends one multipart listing mutation request to the server.

Builds the multipart payload for listing create/edit flows, attaches the authenticated token and optional image bytes, posts the request, and normalizes the JSON response into the legacy flattened response map.
